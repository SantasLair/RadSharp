The first preview of **RadSharp**, Delphi-style rapid application development for C#. Draw a form, double-click a
button to write its handler, press **F9** to run it live, and press **Build** for a small native executable for Windows,
macOS or Linux.

> This is a preview. APIs may change before 1.0. Builds are not code-signed. Read the
> [known limits](https://github.com/SantasLair/RadSharp/blob/main/docs/known-limits.md) before building on it.

## Get started

You need the [.NET 10 SDK](https://dotnet.microsoft.com/download), 10.0.404 or later.

```sh
dotnet new install RadSharp.Templates::0.1.0-preview.1
dotnet new radsharp-app -n MyApp
cd MyApp && dotnet run
```

Or download the designer below, choose **New Application…**, and press F9. The
[getting-started guide](https://github.com/SantasLair/RadSharp/blob/main/docs/getting-started.md) walks through both.

## What's in it

- **The designer**, built with RadSharp itself: a component palette, Object Inspector, Align + Anchors layout with
  snapping and alignment tools, menu, tab-order, column and node editors, undo/redo, and light and dark themes.
  Double-clicking a control writes its handler and opens your IDE (VS Code, Visual Studio or Rider).
- **F9 live run**: compiles the project in memory, unsaved forms included, with its NuGet packages, source generators
  and project references.
- **Your project's own controls** on the palette, in both the standalone designer and Visual Studio.
- **The Visual Studio designer**: `.radform.json` files open in a `[Design]` tab with a RadSharp Toolbox and Properties
  window; handlers open in VS's C# editor.
- **About 40 controls**, custom-drawn by Skia so they look the same on every OS: standard controls, `StringGrid` and
  `DrawGrid` with a 100 000-row virtual mode, `ListView`, `TreeView`, `ListBox`, `ComboBox`, `CheckListBox`,
  `DateTimePicker` and `Calendar`, `PageControl`, menus, toolbars, dialogs, timers and image lists.
- **`Binder<T>` and `Action`**: two-way binding of edit controls to a model with dirty tracking and validation, and
  shared commands for buttons, tool buttons and menu items.
- **Windows and input**: per-monitor DPI with live rescale, mnemonics, window placement, file drag and drop,
  `async` handlers on the UI thread.
- **NativeAOT output**: `dotnet publish` makes a self-contained executable of about 5–6 MB plus the SDL3, Skia and
  HarfBuzz libraries. New projects include a GitHub Actions workflow that builds a Windows zip, a macOS `.app` and a
  Linux tarball and AppImage, with signing steps ready for your certificates.

Form files are JSON (format version 1.0, see the
[spec](https://github.com/SantasLair/RadSharp/blob/main/docs/spec.md)), and the source generator turns each one into
typed fields and `InitializeComponent()`, with no reflection.

## Not yet

Right-to-left text, accessibility, localization, frames and form inheritance, printing, and a web target are not in
this preview. The [known limits](https://github.com/SantasLair/RadSharp/blob/main/docs/known-limits.md) page has the
full list.
